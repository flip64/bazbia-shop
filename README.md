راهنمای نصب و endpointها: docs/coins-api.md
راهنمای ثبت سکه و پک: docs/coins-models.md

پوشه coins را کنار manage.py کپی کنید.
خط CoinsConfig در INSTALLED_APPS و مسیر api/coins/ در urls.py را طبق راهنما اضافه کنید.
اگر مرحله مدل‌ها را قبلاً نصب کرده‌اید خط تنظیمات را دوباره اضافه نکنید.
